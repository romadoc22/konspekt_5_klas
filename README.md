# Головне з підручника — 5 клас

Односторінковий застосунок: обираєш підручник → вводиш сторінку/параграф/тему →
бачиш головну суть. Працює повністю локально в браузері, без реєстрації.

## Запуск без GitHub
Просто відкрий `index.html` (або `konspekt_5_klas.html`) подвійним кліком —
працює офлайн, дані зберігаються в localStorage цього браузера.

## Розгортання на GitHub Pages (без знання git)
1. Створи новий репозиторій на github.com → "New repository".
2. Якщо хочеш приховати код від сторонніх на самому GitHub — постав **Private**
   (це не ховає код від того, хто просто відкриє опубліковану сторінку, див. LICENSE.txt).
3. Кнопка "uploading an existing file" → перетягни `konspekt_5_klas.html`
   (можеш перейменувати на `index.html`, щоб адреса була коротшою).
4. Settings → Pages → Source: гілка `main`, папка `/root` → Save.
5. Через кілька хвилин сайт буде доступний за адресою
   `https://<твій-акаунт>.github.io/<назва-репо>/`.

**Важливо:** навіть із приватним репозиторієм опублікована через Pages
сторінка — публічна (GitHub Pages не має рівнів доступу на безкоштовному
тарифі). Якщо потрібен справді закритий доступ — або сторонній хостинг
із паролем, або сервер, що віддає сторінку лише авторизованим людям.

## Апгрейд: автопояснення через ШІ (опційно)
Базова версія безкоштовна й не потребує нічого. Кнопка "⭐ Апгрейд: авто-ШІ"
дозволяє вставити власний безкоштовний ключ Google Gemini API — тоді сайт
сам генерує пояснення без ручного вставляння тексту.

⚠️ Ключ зберігається відкрито в localStorage цього браузера і видно
в мережевих запитах — не став його на спільному/дитячому пристрої без
нагляду. Це обмеження статичного сайту без власного сервера, не недогляд.

## Захист від копіювання
Дивись `LICENSE.txt` — там чесно описано, що це дає юридичну, а не технічну
підставу: код сторінки видно будь-якому відвідувачу через інструменти браузера.
